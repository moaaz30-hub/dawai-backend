# Dawai Backend 💊

Dawai is a smart medical assistant backend system built for a graduation project.  
It provides APIs for user authentication, medicine search, AI medicine scanning, chatbot integration, search history, and password reset using OTP email verification.

---

## 🚀 Features

- User Registration
- User Login
- Password Hashing using bcrypt
- Medicine Search
- Autocomplete Medicine Suggestions
- AI Medicine Scan Integration
- AI Chatbot Integration
- Chatbot Memory Session
- Search History per User
- Forgot Password using OTP
- Email Sending using Resend
- MySQL Database Integration
- Online Deployment using Railway

---
